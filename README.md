# もどせる（v0.2・試作）── Claude Code で 消えた ファイルを 1 手で 戻す

> 紹介の 記事（note）＝使い方と、作った わけ：https://note.com/ozmaho_lab/n/n166f44be7104

Claude Code に 作業を 頼んで いて、「ファイルが 消えた」「上書きされて 前の 中身が 無い」と なった 時の ための 保険です。
エンジニアで なくても 使える ように、ぜんぶ 日本語で 動きます。

## これで できる こと

- 作業フォルダの 中の **テキストの ファイル**（メモ・文章・表〈csv〉・ページ〈html〉・台本〈py・js〉など）を、自動で 控えます。
  - Claude Code が **命令（Bash）を 走らせる 直前** と、**ファイルを 書いた 直後** に 控えます。
  - だから `rm`（消す）や `mv`（動かす）で 消えても、直前の 中身が 残って います。
- 消えた ファイルは **1 行で 戻せます**。
- 入れた 時に、よく ある 危ない 書き方（`rm -rf`・`git reset --hard`・`git clean`・`git push --force`）を **止める 設定** も 入ります（別の 書き方〈例 `rm -fr`〉までは 止まらない ことが あります＝だから 控えが 本体です）。
- Claude Code を 開く たびに、Claude が **点検の 結果**（✅／❌）を 受け取ります。Claude に「もどせる の 点検は？」と 訊くと 答えます。⚠️ 点検が 見るのは 設定に フックが 入って いるか まで＝フックが 黙って 失敗して いる 時は `一覧` で 控えが 増えて いるかを 見て ください。

## できない こと（正直に）

- 写真・動画・音・大きい ファイル（5 MB 超）は 控えません。→ これらは Time Machine など 別の 控えで。
- 作業フォルダの 外の ファイルは 控えません。
- 控えは 同じ Mac の 中（`~/.modoseru/`）です。Mac が 壊れた 時の 備えには なりません。
- ネットには 何も 送りません。外の サービスも 使いません。

## 要る もの

- Mac（macOS）
- Claude Code
- git（無ければ ターミナルで `xcode-select --install` を 一度 実行）

## 入れ方（1 回 だけ）

1. この フォルダ（`modoseru.py` が 入って いる フォルダ）を Mac の どこかに 置きます。
2. ターミナルを 開き、次の 1 行を 打ちます。`<作業フォルダ>` は Claude Code で 使って いる フォルダの 場所に 置き換えます（フォルダを ターミナルに ドラッグすると 場所が 入ります）。

```bash
/usr/bin/python3 /置いた場所/modoseru.py 入れる <作業フォルダ>
```

3. `✅ もどせる v0.2 を 入れました` と 出たら 完了です。Claude Code を 開き直して ください。

入る 物＝`~/.modoseru/`（道具と 控え）と、作業フォルダの `.claude/settings.local.json`（フックと 止める 設定）だけです。前から 在る 設定は 消しません（元の 設定は `settings.local.json.もどせる前` に 残します）。

## 消えた ファイルを 戻す

ターミナルで、作業フォルダに いる 状態で：

```bash
/usr/bin/python3 ~/.modoseru/modoseru.py 戻す 消えたファイルの名前.md
```

- **消えた ファイル**は、その 場所に 戻ります。
- **上書きされた ファイル**（ファイルは 在るが 中身が 変わって しまった）は、いまの ファイルを 上書き せず、前の 版を `_もどしたもの/` フォルダに 出します。
  - 見比べて、前の 版の 方が 良ければ、Claude Code に「`_もどしたもの` の 版で しおり.md を 置き換えて」と 頼むか、Finder で 前の 版を 元の 場所へ 移して 名前を 戻して ください。
- 数を 付けないと「いまの 中身と 違う 版の うち、いちばん 新しい 版」が 出ます。
- それより 前の 版が 欲しい 時は、後ろに 数を 付けます。

```bash
/usr/bin/python3 ~/.modoseru/modoseru.py 戻す しおり.md 2
```

  `1`＝いまと 違う 版の うち いちばん 新しい 版（数 なしと 同じ）、`2`＝その 1 つ 前、… です。いまと 同じ 中身の 版は 数えません。道具が「もっと 前の 版＝ 戻す しおり.md 2」の ように 次の 一手を 出します。

Claude Code に「消えた ファイルを もどせる で 戻して」と 頼んでも かまいません。

## 戻せる 版・戻せない 版

- 戻せるのは **控えた 時の 版** だけです。控えるのは「Claude Code が 命令を 走らせる 直前」と「ファイルを 書いた 直後」と「Claude Code を 開いた 時」です。
- ご自分で エディタで 書き換えて、控える 前に また 書き換えた 途中の 版は 残りません。大事な 区切りでは 手で 控えて おくと 安心です（作業フォルダの 中で）：

```bash
/usr/bin/python3 ~/.modoseru/modoseru.py 控える "区切りの メモ"
```

- `控える`・`一覧`・`点検` は、作業フォルダ（または その 中の フォルダ）で 走らせます。外で 走らせると「入って いません」と 出ます。

## 控えの 一覧を 見る

```bash
/usr/bin/python3 ~/.modoseru/modoseru.py 一覧
```

いつ 何が 控えられたか、どの 時に ファイルが 消えたか（⚠️ 消えた）が 出ます。表示は 新しい 方から 12 回 分です（控え そのものは もっと 前の 分も 残って います）。

## 点検だけ する

```bash
/usr/bin/python3 ~/.modoseru/modoseru.py 点検
```

## 外し方

```bash
/usr/bin/python3 ~/.modoseru/modoseru.py 外す <作業フォルダ>
```

フックと 止める 設定を 外し、入れる 前の 設定に 戻します（前から 在った ご自分の 設定は 残ります）。入れる 前に 設定ファイルが 無かった 場合は、中身が 空（`{}`）の `.claude/settings.local.json` が 残ります（何も 効かない 空の 設定です）。控え（ホームの 中の `.modoseru/控え/` フォルダ）は 残します（要らなければ ご自分で ゴミ箱へ）。

※ 説明の 中の `~` は「ホーム フォルダ」（Finder の 家の 印の フォルダ）の ことです。

## 困った 時

- 点検に ❌ が 出たら、その 行を Claude Code に 見せて「直して」と 頼んで ください。たいていは `入れる` を もう 一度 実行すれば 直ります。
- この 道具は 試作（v0.2）です。

## 使って よい 範囲

- 無料です。MIT ライセンス（`LICENSE.txt`）＝自由に 使い・直し・配って かまいません。
- 保証は ありません（試作）。大事な ファイルは 別の 控え（Time Machine など）とも 一緒に 守って ください。
